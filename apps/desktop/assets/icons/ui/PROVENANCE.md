# UI icon provenance

These 21 monochrome SVGs are the exact free Hugeicons 1.1.9 shapes previously
embedded through `gpui-hugeicons`. They are copied from upstream commit
`3365154`, reduced to the inventory Axiusflow actually uses, and retain the
upstream MIT license. Fixed stroke colors were changed to `currentColor` so the
icons resolve through the Axiusflow theme rather than bypassing it.
