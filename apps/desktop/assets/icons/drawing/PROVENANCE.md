# Drawing icon provenance

These eight monochrome SVGs were migrated from the owner-supplied Axiusflow
TypeScript application at commit `bf90f2eed30b7428a679598c8a4202a36fcab54c`,
from `src/components/platform/drawing_icons.tsx`.

`trend-line`, `horizontal-line`, `vertical-line`, `ray`, and `rectangle` are
used by the legacy drawing rail. `ruler`, `fibonacci`, and `extended-line` are
retained as future inventory and are not exposed as working tools until the
chart engine supports them.

The source file contains no third-party attribution or separate license. The
assets are treated as Axiusflow-owned application artwork under this
repository's proprietary license. They contain no theme colors and inherit
the current UI color through `currentColor`.
